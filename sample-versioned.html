    Markdown
    この文書は Markdown から作られています。

    ショートカットキー

    読む

    J / K
    次 / 前の見出しへ
    B
    目次の表示を切り替え
    T
    テーマ（OS に合わせる → ライト → ダーク）
    F
    全画面表示

    スライド

    S
    いまの位置から開始（Shift+S で最初から）
    → Space
    次へ
    ←
    前へ
    数字 Enter
    そのページへ
    Home End
    最初 / 最後のページへ
    Esc
    終了

    書く・保存する

    E
    Markdown を編集（入力がすぐ反映される）
    D
    Markdown をダウンロード
    Ctrl+S
    HTML として保存
    Ctrl+P
    印刷・PDF（スライド中は 16:9 で 1 枚ずつ）
    ドロップ
    .md ファイルを読み込む

    版

    V
    版の管理（確定・比較・過去の版）
    N
    比較中: 次の変更へ（Shift+N で前へ）
    Esc
    比較・過去の版の表示を終える

    版の管理
